## Project Overview
This project focuses on cleaning, preparing, and validating an obesity dataset using Python, Pandas, and NumPy. The goal was to transform raw data into a clean and structured format that is ready for analysis, visualization, and future modeling.

## Dataset
The dataset contains health and lifestyle information related to obesity, including age, height, weight, BMI, eating habits, physical activity, and obesity classification.

## Tools Used
- Python
- Pandas
- NumPy
- Google Colab
- GitHub

## Data Preparation Steps
- Loaded and previewed the CSV dataset
- Checked for missing values
- Reviewed and corrected data types
- Removed duplicate rows
- Checked for outliers using summary statistics
- Cleaned formatting issues in categorical columns
- Normalized numerical columns for better comparison
- Created a summary table using the `.describe()` function
- Saved the cleaned dataset as a new CSV file

## Data Quality Checks
I performed data quality checks to make sure the dataset was ready for analysis. These checks included reviewing missing values, duplicate records, data types, outliers, and inconsistent categorical values.
